# Bibliothèque Flutter

Application Flutter mobile pour gérer une collection de livres et de BD.

## Fonctionnalités

- Accueil avec carrousel des lectures en cours
- Bibliothèque avec filtres par statut
- PAL pour les livres possédés mais non lus
- Ajout et modification d’un livre ou d’une BD
- Stockage local hors ligne avec SQLite

## Lancement

1. Installer les dépendances avec `flutter pub get`.
2. Lancer l’application avec `flutter run`.
