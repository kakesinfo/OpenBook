# Contributing to OpenBook

Thank you for your interest in **OpenBook**!

## Current Policy

**Issues are welcome, but pull requests (PRs) and unsolicited feature requests are not welcome yet.**

The project is still evolving rapidly and the architecture/roadmap are managed internally for now (see the [Trello roadmap](https://trello.com/b/rYIRIKxi/yet-another-library-road-map) linked in the README).

## Reporting Issues

Bug reports are always appreciated! When opening an issue, please include:

- **Platform**: Web, Mobile, or API
- **Summary**: A clear description of the bug or unexpected behavior
- **Steps to reproduce**: Minimal steps to trigger the issue
- **Expected vs. actual behavior**
- **Context**: Screenshots, logs, or error messages if applicable
